Simulator library

Three draft simulators, each built from one open-access dementia paper. Not validated.
Read this first. These are software test outputs, not medical advice and not validated measures. A language model proposed each finding, a script checked that the number and sentence occur in the paper, and a person has not yet reviewed every label. Findings the model got wrong were corrected or removed by hand; the changes are listed in the project notes. Papers are used under their CC BY 4.0 licenses.
