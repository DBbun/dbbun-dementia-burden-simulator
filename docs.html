Changes and corrections

These are the changes made after reading the model's findings against each paper. The model's original output was kept as a backup.

Other changes to the site: the page text was relabeled so that it does not suggest federal data feed any simulator (they do not); federal context cards were added to each Evidence tab with no model run; the codebook was frozen as version 0.3 on 2026-11-08 (frozen does not mean validated); audio overviews were added on 2026-11-08.

Interoperability status

Each simulator's downloadable bundle contains a specification (Spec.json), a nine-sheet Excel workbook (saved values, no recalculation), figures and CSV files, a documentation PDF, and a prototype FHIR file with its definitions.

  • FHIR: the file is a prototype of the inputs and results with their provenance. This project has not validated it against a FHIR validator or tested it with any health-record system.
  • Python: each bundle includes a model written as code by the AI model. It is marked "not execution tested" and has not been compared with the page's results.
  • No API: this public site is static. It has no server, collects no data and runs no model in your browser.

AI use and independence

  • Code and page text were written with Claude Sonnet 5.5 (model ID claude-sonnet-5-5).
  • The extraction step in the prototype called claude-sonnet-5, up to four times per paper.
  • The audio overviews use Kokoro-82M, an open-source text-to-speech model, run locally. The scripts were written with Claude and checked by a person against the pages.
  • The codebook was reviewed with Claude Opus 5.5, GPT, Grok and Gemini, as opinions only.
  • A person made all design decisions and reviews the output.
